Pipeline

1. PhotosUploaded, numbered P1..Pn, SHA-256 hashed.
→
2. Vision modelReports only what it sees; every observation cites photo IDs and a confidence.
→
3. Evidence filterDrops observations citing missing or unusable photos, or below the confidence threshold.
→
4. Rules engineDeterministic PASS / FAIL / UNCERTAIN per check, then the shipment decision.
→
5. Reasoning reviewExplains, recommends and drafts a claim. Can only escalate ACCEPT to UNCERTAIN.
→
6. Sealed recordPhotos, observations, verdicts and review hashed into a tamper-evident record.
